# Homebrew tap for Candle

[Candle](https://candlewriter.com) is free, open-source software for planning
and writing novels. To install it on an Apple Silicon Mac:

```bash
brew install --cask lmtrarbach/candle/candle
```

`brew upgrade` keeps it up to date. The cask is updated automatically by
[Candle's release workflow](https://github.com/lmtrarbach/candle); edit
`packaging/homebrew/candle.rb` there, not here.
